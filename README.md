# Wardenclyffe — A Living Field of Ideas

A static, animated site for Wardenclyffe. The homepage is an immersive living field; Services, Work, Shop and Contact pages provide the supporting information.

## Running

Open `index.html` in a browser, or publish this repository from the `main` branch root with GitHub Pages. No build step required.

No checkout, appointment booking, or client-file intake is implemented yet. Do not commit confidential client information or keys.
